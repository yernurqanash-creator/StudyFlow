# StudyFlow — Android Kotlin оқу тапсырмалары менеджері

Университеттегі жоба қорғауға арналған **нақты native Android қосымшасы** (Kotlin). Код VS Code-та ашылады, Android Studio міндетті емес. Интернет пен сервер қажет емес.

## Мүмкіндіктер
- Жаңа тапсырма қосу (атауы, пәні/санаты, маңыздылық деңгейі)
- Тапсырманы орындау/қайтару (checkbox және карточканы басу)
- Барлығы / Белсенді / Дайын фильтрлері
- Тапсырманы ұзақ басу арқылы өшіру
- Орындалу пайызы және статистика
- SharedPreferences + JSON арқылы деректерді телефонда сақтау: қосымша жабылса да жоғалмайды
- Қазақша интерфейс, интернет рұқсаты қажет емес

## Компьютерде кодты өзгерту
1. ZIP-ті аш.
2. VS Code → File → Open Folder → `studyflow_app`.
3. `app/src/main/java/kz/studyflow/app/MainActivity.kt` файлын аш. Тақырыпты, түстерді, бизнес-логиканы осы жерден өзгерте аласың.

## Android Studio-сыз APK жинау — GitHub Actions
1. GitHub.com сайтында **жаңа бос repository** аш (README/gitignore қоспа).
2. VS Code терминалында осы папкада:

```powershell
git init
git add .
git commit -m "Initial StudyFlow Android Kotlin app"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

`USERNAME/REPO` орнына өз репозиторий сілтемесін қой. Git компьютеріңде орнатылған болуы қажет.

3. GitHub → репозиторий → **Actions** → **Build Android APK**.
4. Workflow аяқталып жасыл болған соң сол run-ға кір → **Artifacts** → `StudyFlow-debug-APK`.
5. ZIP ішінен `app-debug.apk` файлын ал.
6. APK-ны Android телефонға жіберіп, орнат. Телефон «белгісіз қолданбаларға» рұқсат сұраса, тек осы өзің құрастырған APK-ға рұқсат бер.
7. Қорғау кезінде APK-ны телефонда ашып, функцияларын көрсет. 

**Ескерту:** ZIP құрамында Gradle wrapper жоқ. GitHub Actions workflow Gradle-ді өзі орнатады. Жергілікті build үшін JDK 17 + Android SDK + Gradle 8.14.3 қажет.

## Жобаның архитектурасы
- `MainActivity.kt`: native Android UI + оқиғалар + логика
- `StudyTask`: Kotlin `data class`
- `SharedPreferences`: жергілікті қарапайым persistent storage
- `JSONArray`/`JSONObject`: тапсырмалар тізімін сақтау
- `app/build.gradle.kts`: Android Gradle Plugin + Kotlin конфигурациясы
- `.github/workflows/android-apk.yml`: GitHub-та APK автоматты жинау

## Қорғауға арналған 45 секундтық сөз
«Менің жобам StudyFlow деп аталады. Ол студенттің оқу тапсырмаларын басқаруға арналған Android қосымшасы. Жобаны Kotlin тілінде жаздым. Пайдаланушы тапсырма қосады, пәнін және маңыздылығын белгілейді, оны орындалған деп қоя алады немесе жоя алады. Барлық, белсенді және аяқталған тапсырмалар бөлек көрсетіледі. Орындалу пайызы автоматты түрде есептеледі. Деректер SharedPreferences пен JSON көмегімен телефонның ішкі жадына сақталады, сондықтан қосымшаны жауып ашқанда жоғалмайды. APK-ны Gradle арқылы жинауға болады.»

## Тексеру сценарийі
1. Қосымшаны аш → статистика 0/0.
2. «Қосу» → «Kotlin жобасын қорғау», пәні «Мобильді бағдарламалау», басымдығы «Жоғары» → Қосу.
3. Екінші тапсырма қос.
4. Бірін checkbox арқылы орында → пайыз өзгеруі тиіс.
5. «Белсенді», «Дайын» фильтрлерін тексер.
6. Қосымшаны жауып қайта аш → тапсырмалар сақталуы тиіс.
7. Бір тапсырманы ұзақ бас → өшіруді раста.

**Мән-жай:** Код пен ZIP жасалды, бірақ осы ортада Android SDK жоқ, сондықтан APK compile/install жасалып тексерілген жоқ. GitHub Actions нақты компиляция нәтижесін көрсетеді.
